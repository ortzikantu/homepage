## Tech Stack

- **Web Framework**: Litestar 2.19+
- **Template Engine**: Jinja2 3.1+
- **Git Operations**: pygit2 1.19+
- **ASGI Server**: Uvicorn
- **Python**: 3.14+

## Features

- Repository browsing with file tree and content view
- Full commit history and commit details
- Contribution heatmap visualization
- Repository statistics and overview
- Git protocol support (push/pull/clone)
- Tag snapshot downloads
- Responsive design with mobile support
